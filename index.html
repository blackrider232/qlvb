🚀 Hướng dẫn 3 bước khởi chạy QLVB Agent trên máy tính (Không cần cài đặt)

BƯỚC 1

1. Tải file `QLVB_Web_Agent.exe` về máy

Bấm nút [Tải xuống QLVB_Web_Agent.exe] ở trên và lưu vào máy tính bạn muốn dùng để chứa hồ sơ văn bản (ví dụ: để ngoài Desktop hoặc thư mục D:\QLVB).

💡 Chạy ngay 100%: File .exe đã đóng gói trọn bộ công cụ tự động hóa và AI, không cần cài Python.
BƯỚC 2

2. Nháy đúp mở `QLVB_Web_Agent.exe` (Tự chạy ngầm)

Nháy đúp chuột vào file QLVB_Web_Agent.exe vừa tải về. Agent sẽ tự động chạy ngầm dưới thanh công cụ (khay hệ thống góc phải dưới màn hình) mà không làm vướng màn hình làm việc. Khi nào cần mở bảng điều khiển đầy đủ, chỉ cần click chuột vào icon Agent dưới thanh công cụ.

⚠️ Lưu ý: Nếu Windows hiện thông báo xanh "Windows protected your PC", hãy bấm vào chữ More info → chọn Run anyway.
BƯỚC 3

3. Tra cứu & Tải văn bản trên Web App

Ngay khi Agent được bật, góc trên bên phải trang web sẽ tự động báo 🟢 Máy trạm Local: Đã kết nối. Bạn có thể chuyển sang Tab Tra cứu nhanh hoặc Quét theo Dự án để tải văn bản ngay!

📂 Lưu trữ Local: Toàn bộ file tải về nằm trong thư mục downloads cạnh file .exe (hoặc thư mục bất kỳ bạn chọn).

💡 Lưu ý quan trọng trong quá trình sử dụng

1. Chế độ chạy ngầm dưới thanh công cụ (System Tray): Khi khởi chạy, QLVB Local Agent tự động thu gọn dưới thanh công cụ (góc dưới bên phải màn hình). Click chuột trái vào icon dưới thanh công cụ để hiện bảng điều khiển đầy đủ; bấm nút thu nhỏ (_) hoặc nút đóng (X) để ẩn lại xuống thanh công cụ. Khi muốn thoát hẳn, bấm [✖ Tắt hẳn Agent].
2. Yêu cầu trình duyệt trên máy tính: Máy tính chạy Agent chỉ cần có sẵn trình duyệt Google Chrome hoặc Microsoft Edge thông thường. Khi bấm "Bước 1: Mở QLVB & Đăng nhập", cửa sổ Pop-up sẽ hiện lên để bạn đăng nhập tài khoản QLVB Hà Nội rồi tự động ẩn xuống chạy ngầm.
